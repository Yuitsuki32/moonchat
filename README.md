# MoonChat 🌙

A dreamy purple-and-blue moonlight-themed chat UI starter.

## What works right now
- Responsive chat interface for desktop and mobile
- Send-message interaction in the current browser preview

## Important
This is a visual starter, not a real multi-user chat yet. Messages are local to the browser. Follow `SETUP.md` to connect Firebase for sign-in and real-time shared messaging before sharing it with friends.
